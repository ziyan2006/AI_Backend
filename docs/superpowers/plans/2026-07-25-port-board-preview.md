# 实物风格端口预览实现计划

目标：创建一个独立 HTML 样式稿，展示深色测试台中的实物风格端口面板。样式稿已归档到 `docs/prototypes/port-board-preview.html`。

架构：单个 HTML 文件内含 HTML、CSS 与原生 JavaScript。页面用 4x4 器件槽位承载四向端口，共 64 个可视端口；槽位位置严格使用积木映射表，端口显示底板模块中的本地接口号。

## 文件

- 创建：`docs/prototypes/port-board-preview.html` — 可直接打开审查的独立预览。

## 实施步骤

1. 搭建深色画布、白色 ABS 面板、16 个器件槽位和状态栏。
2. 为每个器件槽位绘制上、右、下、左四个白色凹槽端口与中心黑色 PCB 触点条。
3. 按映射表生成 16 个槽位：第一、二行依次为 `4-7/3-5/2-3/1-1` 与 `4-8/3-6/2-4/1-2`，第三、四行为 `5-9/6-11/7-13/8-15` 与 `5-10/6-12/7-14/8-16`；实现端口点击和模拟高亮按钮。
4. 依据槽位奇偶区分底板模块本地端口：槽位 1 为上 `P3`、右 `P0`、下 `P1`、左 `P2`，槽位 2 为上 `P5`、右 `P6`、下 `P7`、左 `P4`；检查高亮时状态栏的端口顺序与视觉反馈。

## 验证

页面可加载；映射表中的 16 个槽位周围共有 64 个可视端口；槽位 `1-1` 显示 `P3/P0/P1/P2`，槽位 `1-2` 显示 `P5/P6/P7/P4`；蓝绿色端口高亮和暖黄色槽位选中状态清晰可见。
