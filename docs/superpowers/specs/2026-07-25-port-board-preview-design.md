# 实物风格端口预览样式稿

归档文件：`docs/prototypes/port-board-preview.html`。

## 目标

为现有深色测试台制作独立的 HTML 样式稿，用实物感的白色 ABS 面板替代当前抽象的 8x8 圆点端口网格。该文件仅用于人工确认视觉方向，不接入现有前端代码。

## 布局

- 保留深色、低对比度的测试台背景。
- 主体为一块大号白色拼接面板，包含 4x4 共 16 个器件槽位。
- 每个器件槽位由居中的黑色 PCB 触点条、四周白色凹槽端口、细微投影和螺丝细节组成。
- 四向端口位于器件槽位的上、右、下、左位置，总数为 64 个。

## 编号与交互

- 槽位按用户视角的映射表显示为“底板模块-级联槽位”：第一行从左到右为 `4-7`、`3-5`、`2-3`、`1-1`；第二行为 `4-8`、`3-6`、`2-4`、`1-2`；第三行为 `5-9`、`6-11`、`7-13`、`8-15`；第四行为 `5-10`、`6-12`、`7-14`、`8-16`。
- 每两个纵向槽位是一块方向一致的底板模块；上方是该模块的槽位 1，下方是槽位 2。
- 端口使用底板模块的本地红外接口编号，不使用跨面板连续编号：槽位 1 的上、右、下、左分别为 `P3`、`P0`、`P1`、`P2`；槽位 2 的上、右、下、左分别为 `P5`、`P6`、`P7`、`P4`。
- 默认端口为低亮金属触点；被高亮端口显示蓝绿色光晕，当前选中槽位显示暖黄色描边。
- 样式稿提供单击端口和模拟高亮按钮，方便检查发光反馈与空间层次。

## 边界

- 不改动 src/tuco_ai_backend/frontend 下的生产页面。
- 不调用后端接口，不改变现有运行时端口协议；本稿仅以映射表验证物理位置和本地端口号的展示。
- 不使用外部图片或第三方资源；全部通过 HTML、CSS 和少量原生 JavaScript 呈现。
