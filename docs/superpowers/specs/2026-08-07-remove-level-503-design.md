# 移除进位汇聚关卡设计

## 目标

删除旧 503「进位汇聚」，将原 504 全加器关卡重编号为 503，并统一固件与后端名称：

- 501：个位引擎
- 502：进位引擎
- 503：全加主控

## 行为变更

- 固件关卡树由 `501 -> 502 -> 503(进位汇聚) -> 504(全加器)` 改为 `501 -> 502 -> 503(全加器)`。
- 原 504 的剧情、教程、真值表、学习小游戏和奖励归属全部迁移到新 503。
- 原 503 的三输入或门规则、剧情和专用引导全部删除。
- 后端评测、规划器、提示词和学习活动只识别新的 503 全加器，不再生成或接受 504 关卡用例。
- HTTP 503/504 状态码不属于关卡编号，保持不变。

## 兼容边界

- 固件存档按关卡 ID 保存；升级时把旧 `done_504` 的全加器完成状态迁移为新 `done_503`。
- 旧 `done_503` 对应已删除的进位汇聚关卡，迁移时先清除；只有旧 `done_504=1` 时才写入新 `done_503=1`。
- 固件现有助教诊断改动保持原样，本次只修改关卡内容相关文件。

## 验证

- 后端规则集合包含 501、502、503，不包含 504；503 真值表为全加器双输出。
- 固件自检确认 503 为全加器规则，关卡树中不存在 504，503 前置为 502。
- 后端完整测试和 Ruff 通过。
- 固件使用 ESP-IDF/Ninja 增量构建，不执行 `fullclean`。
